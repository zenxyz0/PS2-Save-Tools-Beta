Convert saves to Mcd001.ps2

Turn .cbs, .psu, .xps, and .max saves into a ready-to-use PS2 memory card (8, 16, 32, or 64 MB) for PCSX2.

      Card size
      A real PS2 only recognizes 8 MB. 16/32/64 MB are for PCSX2 and devices that support them. Bigger cards use more browser memory.
      Everything runs in your browser; no files are uploaded. After the card is built, the page reads it back to verify it, then you can download Mcd001.zip (containing Mcd001.ps2, because the hosted preview cannot save the .ps2 extension directly; the standalone file saves a plain .ps2) or open it straight in the Reader. If you choose an existing card, its contents are kept and saves with the same folder name are replaced. .max files are read with LZARI decompression. Back up your old card before overwriting it.

      Read contents of Mcd001.ps2

      Browse the saves, titles, dates, and files inside a memory card. Search, sort, export to .psu, or delete.

      Everything runs in your browser: nothing is uploaded and your original file is not changed. Tick saves and delete them; the change only counts after you download the modified card and overwrite the old file, so back up first. It accepts PS2 memory cards in .ps2 or .bin format, with or without ECC, including output from the Converter. Save titles are taken from the file icon.sys in each save folder, so some saves only show their folder name. The PS1 tag marks a PlayStation 1 save. Click a save to see the files inside it. If an error appears, the file is usually not a PS2 memory card or its size does not match the card header.

      Copy between cards

      Load two cards, tick saves, then copy or move them from one to the other.

      The destination card is rebuilt with its old contents plus the selected saves; saves with the same folder name are replaced. Changes only count after you download the card, so your original file stays safe. Save folder names cannot be changed here because games look saves up by that name. To split a large card, create an empty card B and move some saves into it.
